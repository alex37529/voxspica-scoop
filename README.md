# VoxSpica — бакет для Scoop

Переносимая сборка VoxSpica: один `.exe` внутри zip, офлайн-распознавание речи,
33 языка, без облака и подписки.

## Установка

```powershell
scoop bucket add voxspica https://github.com/alex37529/voxspica-scoop
scoop install voxspica
```

После установки доступна команда `voxspica` и ярлык в меню «Пуск».
Удаление — `scoop uninstall voxspica`.

## Что нужно знать до установки

- **Модель распознавания не входит в архив.** При первом запуске программа
  спросит язык и скачает модель: около 50 МБ для «малой», до 1.8 ГБ для
  «большой». Языковые установщики с моделью внутри лежат на
  <https://voxspica.4crytobot.xyz/>.
- **Программа не подписана**, поэтому Windows может предупредить о неизвестном
  издателе.
- **Только Windows x64.**

## Как обновляется манифест

У пользователя всё происходит сам: `scoop update voxspica` подставляет новую
версию. `checkver` смотрит последний релиз, `autoupdate` собирает URL по номеру
версии, а хеш берётся из `<архив>.zip.sha256` того же релиза — тем же, что и
в GitHub Releases, так что подмена файла в релизе его не обойдёт.

Но в самом манифесте `version`, `url` и `hash` записаны развёрнуто, и **они
обязаны совпадать между собой**. Забытая из трёх даёт не «грязный файл», а
установку, которая падает на проверке контрольной суммы. Поэтому при выпуске
версии манифест правится скриптом, а не руками:

```sh
git clone https://github.com/alex37529/voxspica-scoop
cd voxspica-scoop
sh scripts/update_scoop_manifest.sh 0.1.8
git diff bucket/voxspica.json   # убедиться, что изменились ровно три поля
git commit -am "VoxSpica 0.1.8 as a Scoop manifest" && git push
```

Скрипт берёт хеш из `.zip.sha256` рядом с архивом релиза, оттуда же, где его
посчитал релизный пайплайн, — так источник суммы не может разойтись с тем, что
лежит в Releases. Если релиз ещё не опубликован, скрипт скажет об этом и
ничего не изменит.
