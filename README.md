# VoxSpica — бакет для Scoop

Переносимая сборка VoxSpica: один `.exe` внутри zip, офлайн-распознавание речи,
33 языка, без облака и подписки.

## Установка

```powershell
scoop bucket add voxspica https://github.com/alex37529/voxspica-scoop
scoop install voxspica
```

После установки доступна команда `voxspica` и ярлык в меню «Пуск».
Удаление — `scoop uninstall voxspica`.

## Что нужно знать до установки

- **Модель распознавания не входит в архив.** При первом запуске программа
  спросит язык и скачает модель: около 50 МБ для «малой», до 1.8 ГБ для
  «большой». Языковые установщики с моделью внутри лежат на
  <https://voxspica.4crytobot.xyz/>.
- **Программа не подписана**, поэтому Windows может предупредить о неизвестном
  издателе.
- **Только Windows x64.**

## Как обновляется манифест

`scoop update voxspica` сам подставляет новую версию: `checkver` смотрит на
страницу последнего релиза, `autoupdate` собирает URL по номеру версии, а хеш
берётся из `SHA256SUMS.txt` того же релиза — тем же, что и в GitHub Releases,
так что подмена файла в релизе его не обойдёт.
